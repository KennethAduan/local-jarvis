# Jarvis Kokoro native helper

This standalone process synthesizes British George speech offline. It opens and SHA-256 verifies all five pinned public model assets before engine creation; on Windows it holds read-only handles that deny write and delete sharing while the engine exists. Kill the helper to cancel inference, and discard responses belonging to cancelled requests. It does not capture or play audio.

Build with Rust MSVC and Visual Studio 2022 C++ Build Tools: `cargo test --locked` and `cargo build --release --locked` in this directory. The first build of sherpa-onnx-sys downloads its matching native runtime. For packaging, run `bash stage-windows.sh x86_64-pc-windows-msvc <private-destination>`; ship that directory as a unit and do not place its DLLs beside the microphone helper. It contains `jarvis-kokoro.exe`, `onnxruntime.dll`, `onnxruntime_providers_shared.dll`, `sherpa-onnx-c-api.dll`, `sherpa-onnx-cxx-api.dll`, and `licenses/`. The public model pack is separate, not included in that directory.

Run `jarvis-kokoro --model-dir <absolute-directory>` and send one UTF-8 JSON object per line containing `id`, `text`, `speed`, and `volume`. Each response is a JSON line with the same `id` and either `error`, or `rate`, `pcm` (base64 signed 16-bit little-endian mono), and `end`. Invalid JSON or an overlong request has an empty response id. Input is bounded to 8192 bytes per line and 240 Unicode characters per segment; output is capped at 60 seconds. The process retains the model and processes requests sequentially until EOF. Arguments or diagnostics go to stderr; protocol data alone goes to stdout.
